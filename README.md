# Summeet

Summeet is a dating&meeting app, but instead of the bar you hit the mountain.

Summeet is unique:
- genuinity rather than performance: you search hikes, rather than profile pics
- alternative dating: date=hike, and hikes should involve at least 3 people
- no profile swiping, no algorithm choosing for you. All hikes are displayed equally on a map, you request a spot if you want to join, or you propose one yourself.
- community project: this is not a big-tech company project, the community is involved from the beginning through the community chat and the feedback form

And most importantly, Summeet is built to please, since it starts as a gift.
